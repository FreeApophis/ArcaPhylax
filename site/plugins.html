Plugins

The easiest way to install a plugin is the Plugins page in ArcaPhylax: it shows this list, picks the right package for your computer and keeps plugins up to date. You can also download a package here and use Install from file….

Every package is signed. ArcaPhylax checks the signature before installing and refuses packages from unknown publishers.
